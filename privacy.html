SPLIT BILL

隱私權政策

最後更新：2026 年 8 月 31 日

Splitbill（分帳系統）是一套專為朋友、旅遊夥伴或小群體記帳、分攤共同開銷所設計之工具。本文件詳細說明在使用本服務（包含 Web 網頁版、PWA 與 Android App 原生應用程式）時，我們如何收集、使用、保護及共享相關資料。

我們會收集的資料

  • 帳號與個人檔案：顯示名稱、個人大頭貼圖片、電子信箱（選填）、密碼（由 Supabase 加密儲存，無明文存取），或透過 Google／Discord 快速登入時取得之帳號識別碼、信箱與顯示名稱。
  • 記帳與分攤紀錄：群組內新增之支出項目、金額、幣別、消費日期、代付人與分攤成員名單，以及還款與結清紀錄。
  • 發票與收據影像（選用）：當你使用「📷 AI 拍照自動拆單」功能時，當次拍攝或選取之收據發票圖片僅於記憶體中進行影像前處理與單次辨識，絕不留存、亦不任意公開或用於模型訓練。
  • 定位資訊（選用）：開啟「總覽」頁或「快速記帳」時，若瀏覽器/裝置允許定位，系統會自動取得一次性地理座標，透過第三方地圖服務（OpenStreetMap Nominatim）反查所在國家與城市，藉此推薦適合的記帳幣別、或在您移動到不同國家時提醒您。座標本身不會回傳或保存於我方伺服器，僅將反查後的國家代碼與城市名稱存放於裝置本機（localStorage）。
  • 群組留言與互動：於「群組留言板」發布之內容僅限同一群組之成員可見。
  • 通知推播識別碼：若開啟即時推播，系統會儲存瀏覽器 Web Push 或 Android Firebase Cloud Messaging (FCM) 提供之加密 Token，僅在群組帳務異動時發送通知。
  • 裝置本機偏好：深色/淺色主題模式、當前幣別顯示設定等，僅儲存於使用者裝置本機（localStorage），不上傳伺服器。

裝置權限說明（Android 應用程式）

我們的 Android 原生 App 僅向系統請求最基礎且必要之權限：

  • 相機與相片選取（CAMERA / Photo Picker）：僅在主動點擊「📷 拍照自動拆單」或「上傳/裁切大頭貼」時請求授權，用於拍攝收據或選取頭像。
  • 地理位置權限（LOCATION / GPS）：開啟「總覽」頁或「快速記帳」時會自動請求一次性定位（非持續背景追蹤，也不會在您不使用本服務時定位），用於偵測所在國家/城市藉此推薦適合的記帳幣別。
  • 檔案快取與原生分享（Filesystem / Share）：用於將產生的對帳單與結算圖片暫存至應用程式快取並調用系統原生分享面板發送至 LINE、社群軟體。
  • 網路連線（INTERNET）：用於載入最新畫面及與 Supabase 雲端資料庫同步帳務。
  • 通知與震動（POST_NOTIFICATIONS / VIBRATE）：用於接收即時帳務更動與還款推播。
  • 絕無不必要權限：我們絕不存取 通訊錄、通話紀錄、麥克風或讀取裝置其他無關檔案。

資料使用目的

  • 提供帳號辨識、頭像同步、共同分帳運算與最簡還款路徑推薦。
  • 於帳務新增、修改或還款確認時發送即時同步通知。
  • 絕不將使用者資料用於商業廣告投放、行銷推廣或轉售予任何第三方。

資料儲存與安全防護

所有帳務資料均儲存於 Supabase 企業級雲端資料庫，並由資料庫層級權限規則（Row Level Security, RLS）嚴格保護，確保僅具備群組授權之成員可存取該群組帳目，群組間彼此完全隔離。若同一帳號同時加入多個群組，各群組之帳務資料仍分別獨立儲存與保護，切換群組不會使不同群組間的資料互相顯示或混用。

第三方服務整合

  • Supabase：提供帳號身份驗證、雲端資料庫與後端安全授權機制。
  • Google Firebase (FCM)：Android 原生背景推播服務。
  • 多模態 AI 視覺模型端點（Google Gemini / OpenRouter 等）：用於發票收據文字與結構化金額解析。
  • OpenStreetMap Nominatim：用於將定位座標反查為國家/城市名稱，藉此推薦記帳幣別，僅傳送座標、不含帳號或個人識別資訊。
  • Google / Discord OAuth：提供便捷安全之第三方單一登入（SSO）。
  • Cloudflare Turnstile：登入防護與防止惡意機器人濫用。

使用者權利

  • 隨時於「設定」頁面修改顯示名稱、信箱、密碼或更新個人大頭貼。
  • 隨時自主開啟或停用推播通知功能。
  • 退出群組：歷史共同帳務將維持完整以供其他成員對帳，但該成員將不再列入後續分攤名單。
  • 銷毀帳號：結清全數群組款項後可隨時銷毀帳號，系統將全面撤銷登入權限。

資料保留與刪除

只要帳號或群組持續存在，相關帳目即會安全保存作為對帳依據。若管理者選擇刪除群組，該群組內所有支出、還款、留言與成員資料將永久清除且無法復原。
